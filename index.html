About

Research at the boundary between evaluation and adaptation.

I am an undergraduate researcher at UC Berkeley, where I work on systems that turn execution traces into structured, reusable evidence about model and agent behavior. My work asks what an evaluator can learn from the shape of a failure that a scalar score cannot show.

I have worked with researchers across BAIR, the Sky Computing Lab, and the GEPA team. My projects span mathematical-proof evaluation, adaptive taxonomies for agent systems, and failure-aware ranking for prompt and program optimization.

02

Selected research

Failure evidence as an interface for improving AI systems.

Lead researcher 2026–present

FailureRank

A gold-free framework for ranking candidate LLM programs from execution traces and estimating their performance across repeated runs and unseen tasks. The work studies taxonomies designed for comparison, robustness assessment, and future learning-loop integrations.

Equal-contribution co-first author 2025–present

AdaMAST

Adaptive, evidence-grounded failure taxonomies for agent systems. I helped define adaptation operationally, built the end-to-end taxonomy pipeline and its evolutionary-search and runtime integrations, and originated the Claude Code and Codex integrations.

Paper Code
Equal-contribution first author 2026–present

Learned Error Diagnosis for GEPA

An outcome-blind judge that diagnoses failure modes from execution traces and enriches the reflection data used by prompt optimization. I designed and built the method, evaluation infrastructure, and adapter-compatible integration.

Article Code Upstream PR
Researcher and co-author 2025

ProofGrader and ProofBench

Fine-grained evaluation of Olympiad-level natural-language proofs. I built the initial marking-scheme generator, produced core expert annotations and qualitative analysis, and developed evaluator variants used in the final system and ablations.

Paper ICLR poster
